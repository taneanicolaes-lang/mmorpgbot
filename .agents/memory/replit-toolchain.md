name: Требования Replit к инструментам
description: Совместимость codegen и Python-окружения импортированного workspace.
---

Для генерации API-кода в этом workspace нужен Node.js 24: Orval 8.41 использует `Map.groupBy`, которого нет в Node.js 20.

Python-процесс workflow должен получать библиотеки в том же интерпретаторе, который вызывается командой workflow. Управляемый Replit Python и системный Python могут отличаться; Python-модуль, установленный через callback для `pyproject.toml` в корне этого workspace, может попытаться собрать несуществующий пакет из `src/`.

**Why:** импортированный проект запускался на Node 20, а попытка стандартной установки Python-пакетов встретила несовпадение между корневым манифестом зависимостей и фактической структурой пакета.

**How to apply:** перед codegen использовать Node 24; при проблемах с импортами Python проверить `sys.executable` именно в окружении workflow и направить установку зависимостей туда.
