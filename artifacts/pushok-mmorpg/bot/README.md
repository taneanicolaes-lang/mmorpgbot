# Telegram-бот «Пушок»

Бот написан на Python и aiogram 3. Он использует тот же игровой API, что и веб-панель, поэтому профиль, монеты, питомцы, предметы и архив браков хранятся на сервере, а не в памяти бота.

## Запуск

1. Установите Python 3.11 или новее.
2. Установите зависимости: `python -m pip install -r requirements.txt`
3. Добавьте секрет `BOT_TOKEN` в окружение. Никогда не помещайте токен в исходный код или архив проекта.
4. Запустите API-сервер проекта. По умолчанию бот обращается к API через локальный прокси Replit.
5. Запустите бота командой `python main.py` из этой папки.

Если API работает по другому адресу, задайте `API_BASE_URL`, например `https://ваш-домен/api`.

## Команды

`/start`, `/menu`, `/profile`, `/inventory`, `/pets`, `/shop`, `/battle`, `/raid`, `/guild`, `/marriage`, `/divorce`, `/link`.

Чтобы связать Telegram с персонажем веб-панели, нажмите **Привязать Telegram** в панели и отправьте боту полученную команду `/link КОД`. Код действует 10 минут. Если у обоих профилей есть прогресс, бот попросит выбрать `/link КОД web` или `/link КОД telegram`. Выбранный персонаж станет общим; второй профиль останется в базе отдельно, но не будет доступен через эту связку.

Также распознаются короткие русские триггеры: `дуэль`, `брак Имя`, `дом`, `аукцион`, `питомцы`, `магазин`, `кузнец`, `рейд`, `гильдия`, `профиль`, `инвентарь`, `покормить`.

Бот и веб-панель используют общую игровую базу PostgreSQL через API. Команды для других игроков защищены заголовком `X-Bot-Token`, который бот формирует из `BOT_TOKEN`; секрет не записывается в файлы и не выводится в логи.
